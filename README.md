AGRI_LTY est une application web de monitoring destinée aux exploitants agricoles. Elle permet de centraliser le suivi des parcelles, les données météorologiques, les alertes de vigilance et les observations effectuées sur le terrain.


Récuperation du projet :

git clone https://github.com/votre-username/agri_lty.git

Installation des dépendances :

pip install flask

Lancement de l'application :

python app.py

Accéder à l'application
Ouvrez votre navigateur à l'adresse : http://localhost:500
